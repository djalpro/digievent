Site statique en un seul fichier (`index.html`, HTML, CSS et JavaScript sans dépendance), hébergé avec GitHub Pages.

## Modifier le site

1. Modifier `portfolio/index.html` (directement sur GitHub avec le crayon ✏️, ou en local).
2. Enregistrer le commit sur la branche `master` : le site se met à jour en 1 à 2 minutes.

Pour ajouter une photo : déposer `photo.jpg` dans ce dossier `portfolio/`, puis dans `index.html` remplacer
`<span role="img" ...>AS</span>` par `<img src="photo.jpg" alt="Portrait d'Abdeldjalil Soudani">`.
